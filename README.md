# Estructuras de Datos en Java - OmegaUp

Repositorio con implementaciones de estructuras de datos basicas (Nodo, Pila, Cola) y codigos adaptados para resolver problemas en la plataforma OmegaUp.

## Descripcion de Codigos 

Ejercicio 1: Simula los autos metidos en un callejón utilizando una pila, contando cuántos vehículos se retiran hasta encontrar la placa buscada. Obtuvo una ejecución correcta del 100.00% en OmegaUp.   


Ejercicio 3: Implementa una pila básica que obedece instrucciones numéricas (1 para insertar, 2 para eliminar y 3 para consultar el elemento superior o mostrar "Empty!"). Cuenta con su validación aprobada en plataforma.   


Ejercicio 5: Modela el orden en que una telefonista realiza llamadas utilizando una pila con papelitos acumulados por minuto. Logró una calificación perfecta de 100.00%.   

Ejercicio 7: Administra una pila interactiva capaz de conocer y consultar el número máximo actual de forma instantánea sin necesidad de recorrer toda la estructura. Aprobado correctamente.   

Ejercicio 9: Revisa el correcto balance y anidación de paréntesis, corchetes y llaves en cadenas de caracteres, imprimiendo "SI" o "NO" según corresponda. Cuenta con 100.00% de efectividad.   

Ejercicio 11: Define las funciones esenciales de una pila con nodos enlazados (agrega y saca) diseñadas específicamente para evaluadores automáticos que llaman directamente a los métodos.

Ejercicio 13: Simula la atención en un banco combinando dos tipos de estructuras: la fila 1 funciona como cola (FIFO) y la fila 2 opera como pila (LIFO) basándose en eventos de llegada y atención.
